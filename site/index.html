Six bets on the felt

Step two: the agent writes six fundamentally different directions. Step three: a real random number picks one. These are the six it wrote for this very page — throw the die and watch where it lands.

This page rolled a 1. Two dice hit the felt — the crimson one decides. On a real run there are no re-rolls.

House rules

Five mechanics, run every time. None of them is “try harder.”

Ambition, stated up front

The brief isn’t “make a page.” It’s demonstrate extreme capability, taste and artistic flavour. Every choice aims at showcase, not adequate.

A mixture, never a gimmick

At least three advanced techniques per build — 3D, shaders, scroll choreography, novel type, unusual layout — each earning its place in one concept.

Real assets

Generated images, animated stills, procedural art. Never a CSS gradient pretending to be a photo.

The dice pick the lane

Your house style is off the table. Six candidates, one $RANDOM, and the roll stands.

Iteration you can see

Nothing ships on pass one. Three rounds of screenshot, audit, fix — eyes on pixels, not code.

Sign the marker

Before a line of code, the roll is locked into a contract. Every critique pass is scored against it. This is the one behind the page you’re reading.
